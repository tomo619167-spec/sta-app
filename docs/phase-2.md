# Phase 2 — 学習ロードマップ

テーマ詳細のコンパクトな進捗、またはテーマのメニューからロードマップ管理画面を開きます。日常の学習項目一覧と、テーマ・項目別の学習開始導線は維持します。

## 管理できること

- テーマ全体の到達目標を編集
- 既存の学習項目の追加・編集・確認付き削除
- 「並び替え」の上下ボタンで表示順を変更。順序は即時保存
- 項目を展開して到達目標、習得度変更、アウトプット、理解を深めるへ移動
- 全項目数、4段階それぞれの項目数、説明できる以上の項目数、未評価の項目数を確認

「次に取り組む」は、表示順に未着手または学習中を探し、該当しなければ未評価を提示します。説明できる・定着したのみの場合は完了状況を表示します。提案を押すとその項目を展開し、一覧から別の項目も選べます。並び替えや習得度の引き下げにも追従します。

習得度は既存の4段階と変更履歴を利用します。テーマの習得度・項目の習得度・各回のアウトプット完成度は独立し、平均や自動連動はありません。旧％評価は記録に保持し、進捗には使用しません。

## 外部AI向けプロンプト

「外部AIで作る」で科目・テーマを確認し、到達目標、学習レベル（高校・大学・その他）、任意の補足情報を入力します。到達目標の初期値はテーマの学習目標ですが、生成用の変更だけではテーマを更新しません。

固定プロンプトは論理的な順序、初学者向けの前提知識、確認可能な行動の到達目標、細分化しすぎない項目数、指定JSONのみの出力を指示します。確認後にクリップボードへコピーし、ユーザー自身が外部AIに貼り付けます。コピーに失敗した場合は「プロンプトを選択」から端末のコピー操作を使えます。アプリによるAI API呼び出しや外部送信はありません。

## JSON version 1

プロンプトの例・アプリ内の形式例・検証は同じ`lib/roadmap-json.ts`で管理します。

```json
{
  "version": 1,
  "subject": "世界史",
  "theme": "フランス革命",
  "items": [
    {
      "title": "革命前のフランス社会",
      "goal": "身分制度と税負担の関係を自分の言葉で説明できる"
    },
    {
      "title": "革命が起きた原因",
      "goal": "政治・経済・思想の観点から革命の原因を説明できる"
    }
  ]
}
```

| フィールド    | 条件                                |
| ------------- | ----------------------------------- |
| version       | 数値の1。未対応バージョンは拒否     |
| subject       | 1〜40文字。取り込み先の科目と一致   |
| theme         | 1〜80文字。取り込み先のテーマと一致 |
| items         | 1〜50件。配列順を学習順として使用   |
| items[].title | 1〜120文字の空でない文字列          |
| items[].goal  | 1〜1,000文字の空でない文字列        |

文字列は前後の空白を除去します。JSON全体は100,000文字までです。上記以外のキー、ID、習得度、Markdownのコードブロックは受け付けません。構文不正・型・必須項目・長さ・取り込み先の不一致は、対象フィールドを含むエラーとして表示します。

「プレビュー」では保存せず、全項目の名前と到達目標を確認します。既存項目または取り込み内でタイトルが重複すると、該当行と「重複した項目も追加する」を表示し、明示的な確認なしに登録しません。重複判定と科目・テーマの照合はNFKC正規化、前後空白除去、連続空白の統一、大文字小文字の同一視で比較します。類似表現の意味的な判定は行いません。

## 保存とデータ保護

IndexedDB名`yohaku-study`・バージョン4・ストア構成は変更しません。このPhaseのマイグレーションは不要です。旧バージョンからの既存の移行経路と原本退避も維持します。

テーマ全体の到達目標は既存の`Theme.description`、項目は既存の`items`を使用します。古い`Theme.roadmap`配列は変更しません。目標編集は保存時の最新のテーマを読み、目標と更新日時だけを変更します。

並び替えは最新の項目一覧を読み、同一トランザクションで位置を更新します。ID、到達目標、評価、学習記録は維持します。上端・下端の範囲外移動は行いません。

JSON取り込みは保存時にも形式・科目・テーマ・重複を再検証します。全項目を新規IDで末尾へ追加し、既存項目・テーマの目標・記録・評価・関連IDは更新しません。新項目の4段階評価はユーザーが選ぶまで未評価です。保存失敗時は一括追加全体をロールバックし、途中までの項目を残しません。入力とプレビューは再試行のため保持します。並行取り込みで増えた重複や名前変更も保存時に確認します。
