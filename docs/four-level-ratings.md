# 科目アイコンと4段階評価

## 操作

科目名からキーワードでアイコンを自動設定します。数学Ⅰ・線形代数・英語・世界史／日本史・物理・化学・生物・経済学・情報などに対応し、不明な名前にはノートを使います。AI APIは使用しません。

「ホームの… → 科目を管理 → 科目の… → アイコンを変更」で9種類と「自動」を選べます。テーマ作成中の科目選択画面からも変更できます。手動設定は名称変更や再読み込みでも維持し、明示的に「自動」に戻すまで再設定しません。

テーマ・項目の「習得度」から4段階を選びます。同じ画面で変更履歴を確認でき、評価を下げることもできます。

| 段階 | 習得度：知識の定着                 | アウトプット完成度：今回の説明                     |
| ---- | ---------------------------------- | -------------------------------------------------- |
| 1    | 未着手：まだ学習していない         | まだ難しい：ほとんど説明できなかった               |
| 2    | 学習中：知識を取り入れている       | 一部できた：断片的には説明できた                   |
| 3    | 説明できる：自分の言葉で説明できる | 概ねできた：重要な内容を説明できた                 |
| 4    | 定着した：時間を空けても思い出せる | 十分できた：根拠や知識同士のつながりまで説明できた |

アウトプット画面の「学習を記録」で今回の完成度を選びます。未評価でも保存でき、前の回の評価は引き継ぎません。対象ごとの画面に全履歴を表示し、記録画面でも種類をアウトプットに絞れます。「理解を深める」と一般メモには完成度の入力を表示しません。

習得度と完成度、テーマと項目はそれぞれ独立しています。平均や自動連動で評価を変更する処理はありません。

## 保存・移行

DB名は`yohaku-study`を維持し、バージョンを4へ更新します。同じブラウザ・オリジンで更新してください。

| 保存先               | 内容                                                          |
| -------------------- | ------------------------------------------------------------- |
| subject-icons        | 科目ID、icon、source（auto/manual）、updatedAt                |
| mastery-history      | 自動採番キー、themeId、targetType、targetId、level、changedAt |
| records.outputRating | 今回の4段階評価。未評価ならフィールドなし                     |
| records.completion   | 旧％評価。原値を保持                                          |

v3の既存6ストアは移行時に書き換えません。追加ストアに科目の自動アイコンだけを作成し、習得履歴は空で開始します。旧0%・100%や旧completedを新しい評価へ変換しません。旧評価は記録に「旧評価 60%」、旧completedは項目に「旧版：習得済み」と表示します。

新評価はユーザーが選ぶまで「未評価」です。進捗でも未評価を別枠にし、対象項目の直近の習得度を段階別件数とセグメントで示します。テーマ自身への評価は集計へ混ぜません。

習得度は変更ごとに追記します。連番IDで同時刻や時計変更時にも最新の選択を特定できます。アウトプット記録も対象種別・ID、ISO日時、評価を持ち、将来の時系列グラフに利用できる構造です。

移行はversionchangeトランザクション内で行い、失敗時はv3全体へ戻ります。再試行・再読み込みで二重登録しません。v1/v2からも従来の原本退避を経てv4まで同一トランザクションで進みます。科目とアイコンの作成・更新は原子的です。項目削除はその項目の習得履歴のみを、テーマ削除は配下の習得履歴を削除します。

## 検証

- ビルド・型チェック：成功
- 保存処理・移行テスト：20件成功
- ブラウザE2E：45件成功（スマホChromium／WebKit、PC Chromiumで各15シナリオ）

旧ストアの一致、旧％保持、移行失敗の復旧、関連科目名、手動アイコンの保持、評価の下降と履歴、対象整合性、評価の独立性、未評価の回、削除範囲を検証しています。

ブラウザテストはスマホChromium／WebKit、PC Chromiumを使用します。表示領域の縮小・移動時の入力・選択・保存、320px幅、動きを減らす設定も対象です。
