# テーマ詳細から学習を始める

## 変更内容

テーマ詳細に学習項目を直接表示し、項目を開く→学習ボタンの2タップでアウトプット・理解を深めるを始められます。既存の項目一覧・学習ボタン・学習画面を再利用しています。

- 科目名・テーマ名・確認用の習得度バッジと編集メニューを先頭に配置
- テーマ詳細だけヘッダーをコンパクトにし、学習目標は必要な時に開く形式へ変更
- 大きなロードマップカードを廃止。「説明できる以上：N / 全項目」のリンクから詳細管理へ移動
- 学習項目は保存済みの順序で初期4件を表示。「すべて表示」で全件を開き、少ない表示にも戻せる
- 各項目に習得段階を表示。展開すると到達目標・習得度の変更・2つの学習ボタンを表示
- テーマ全体の学習ボタンは項目一覧と別に横並びで配置。過去問・演習、集中、学習記録も維持

「説明できる以上」は項目の最新の習得度が3または4の件数です。未評価を含む全項目数を分母とし、テーマ自身の習得度やアウトプット完成度は集計へ混ぜません。

習得度バッジは確認専用です。テーマ全体の評価変更は「… → 習得度を変更」で行い、従来の4段階・変更履歴・保存処理を使用します。学習項目からも同じ編集画面を開けます。

## 起動元と戻り先

テーマ詳細の項目から開始する時は、既存のitem IDに`from=theme`を添えます。対象は従来どおりテーマID・項目IDの整合性を検証し、無効な項目をテーマ全体へ切り替えません。

「テーマに戻る」で同じ項目を展開します。5件目以降から戻る場合は全件表示へ自動で切り替えます。ロードマップ管理画面から開始した場合の戻り先は従来のままです。任意のURLへリダイレクトする処理は追加していません。

## データ保持

IndexedDBの名前・v4スキーマ・保存アダプター・モデル・マイグレーションは変更していません。展開・全件表示・学習画面への移動は表示だけの操作です。旧％評価、科目アイコン、習得履歴、テーマ・項目・記録はそのまま使用します。
