# 学習テーマ・項目の学習導線改善

## 画面と共通化

テーマ詳細は次の順に表示します。

1. 科目・テーマ名
2. 習得済み項目数・進捗バー。タップでロードマップへ
3. 日常学習：アウトプット / 理解を深めるを横並び。対象はテーマ全体
4. 過去問：別セクション。科目を主対象とする画面へ

既存の「集中する」、テーマ管理、学習メモ、履歴も維持しています。

ロードマップの項目をタップすると到達目標・習得状態・日常学習の2ボタンを展開します。複数項目を開けるRadix Accordionを使い、開閉アニメーションとreduced-motion対応を追加しました。到達目標は既存の項目編集フォームから設定できます。未設定の旧項目には「未設定」を表示します。

テーマ・項目用の学習画面は分けず、`LearningScreen`と`DailyActions`を共用します。

| 起動元 | URLの例                   | 対象      |
| ------ | ------------------------- | --------- |
| テーマ | `/themes/T/output`        | theme / T |
| 項目   | `/themes/T/output?item=I` | item / I  |
| テーマ | `/themes/T/deepen`        | theme / T |
| 項目   | `/themes/T/deepen?item=I` | item / I  |

画面と記録フォームに現在の対象を表示します。項目から戻る際は、ロードマップの該当項目を展開します。存在しない・削除済み・別テーマの項目、空のitem指定はエラーとして扱い、テーマ全体へ暗黙に切り替えません。保存層でも親テーマとの対応を検証します。

過去問の新しい入口は`/subjects/S/past-exams?theme=T`です。科目IDが主対象、テーマIDは任意の関連フィルターで、将来の科目単位の管理へ拡張できます。従来のテーマ配下の過去問URLも同じコンポーネントへ接続しています。

## 学習記録と完成度

新しい記録は、既存の`themeId`・`note`・`studiedAt`・`id`に以下を持ちます。

- `targetType`: theme / item
- `targetId`: 対象のID
- `activity`: memo / output / deepen
- `completion`: 任意の0〜100の整数。未入力ならフィールドを保存しない

テーマIDは集約・関連検証用として維持し、実際の学習対象は対象種別とIDの組み合わせで判断します。記録一覧には対象ラベルを表示し、履歴はテーマ全体 / 学習項目で絞り込めます。

完成度は対象ごとの自己評価です。完成度を設定した最新の記録を表示します。0%と未設定を区別し、完成度を設定しないメモで既存の評価を消しません。項目からテーマへの平均・自動集約はありません。ロードマップの進捗は習得チェックから計算し、記録の完成度とは別です。

## IndexedDB v3

DB名は`yohaku-study`を維持し、v1またはv2からv3へ自動移行します。

- 既存の科目・テーマ・項目・記録を維持
- v2の項目には到達目標`goal`を追加。未設定なら空文字
- 記録原本を`legacy-records-v2`に退避
- 旧記録にtheme対象、元のthemeId、memo活動を付加。本文・ID・日時・その他の既存フィールドは保持
- `[targetType,targetId]`の複合インデックスを追加
- v1からは既存の科目階層移行を先に完了し、同じversionchangeトランザクション内でv3処理を続行

失敗時はストア作成とデータ更新を含め全体をロールバックし、元のv1/v2を保持します。成功後は二重移行しません。退避原本も同じブラウザ内にあり、外部バックアップではありません。

項目を明示的に削除する場合は、その項目を対象とした記録のみを同じトランザクションで削除します。テーマ削除では全項目・全記録・関連する退避原本を削除します。確認画面に削除範囲を表示します。
