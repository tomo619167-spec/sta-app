# TRACE Note — Design Ver.1

学びの軌跡を、ノートに残す。既存の学習機能を維持し、知的な誌面と鉛筆の線を組み合わせたデザインへ刷新しました。

## 画面とブランド

- ヘッダー・設定・ページタイトルをTRACE Noteへ変更。SVGのアプリアイコンも追加
- ホーム：日付と本の線画、実データから計算する習得率・テーマ数・習得項目数・記録数、科目別進捗、テーマ一覧、直接使える科目追加
- テーマ：大きな明朝見出しと鉛筆の下線、学習目標、ロードマップ進捗、横並びの日常学習、独立した過去問・集中・記録
- ロードマップ：縦の鉛筆タイムライン、状態の凡例、展開する到達目標・習得操作・共通の学習ボタン
- フォーム、履歴、設定、準備中の画面も同じ配色と操作サイズへ統一

## デザイントークン

`app/tokens.css`が配色・フォント・文字サイズ・余白・角丸・線幅・操作サイズ・動きの共通定義です。構造は`app/components.css`、外観は`app/trace.css`に分離しています。

| 用途         | 色      |
| ------------ | ------- |
| 紙           | #F7F4EC |
| 本文         | #343630 |
| アクセント   | #777F66 |
| 装飾の薄い線 | #B8B3A7 |
| サーフェス   | #E8E4D9 |
| 補助テキスト | #626658 |
| 塗りボタン   | #626A54 |

基本のアクセントは図形・進捗に使用し、細かな文字には濃い補助色を使います。紙と本文のコントラスト比は約11.1:1、塗りボタンの文字は約5.1:1です。淡いMuted色を本文に使いません。

見出しはOS標準のセリフ・明朝、操作と本文はゴシック、日付・数値はセリフです。本文に手描きフォントを適用せず、外部フォントへの通信も追加しません。主要な操作は44px以上、入力文字は16pxを基本にします。

薄い紙の質感、揺らぎのある罫線、SVGの線画、ハッチング入りの進捗・状態マーカーで表現します。ビットマップ画像は追加していません。`prefers-reduced-motion`では展開・折りたたみの動きを停止します。

## データを変更しない表示

IndexedDB名`yohaku-study`、バージョン3、ストア、ID、マイグレーションは変更していません。ブランド名に合わせてDB名を変えると既存データを読めなくなるため、内部名は維持します。

- 未学習：未習得で、項目単位の記録なし
- 学習中：未習得で、項目単位の記録あり
- 習得済み：既存の`completed`がtrue

状態は読み取り時に計算し、既存項目や記録を書き換えません。習得済みを解除すると、記録のある項目は学習中へ戻ります。テーマ全体の記録は、全項目を学習中へ変える根拠にはしません。

ホーム全体と科目別の進捗は、対象の習得項目数÷全項目数です。テーマごとの進捗率を単純平均しません。項目がない場合は0%。テーマと項目の完成度は従来どおり独立し、記録の完成度をロードマップ進捗へ流用しません。

- `npm run build`：成功
- `npm run typecheck`：成功
- `npm test`：12件成功
- `npm run test:e2e`：36件成功（3ブラウザ構成×12シナリオ）

E2EはPixel 7相当のChromium、iPhone 13相当のWebKit、PC Chromiumを使用します。既存の作成・編集・削除・科目変更・移行・学習対象・独立した完成度・保存失敗・キーボード表示領域のテストを維持しました。

追加したテストでは、実データのサマリー、3種類の項目状態、完成度90%でも習得率33%を保つこと、再読み込み前後でIndexedDBの全ストアが同一であること、科目の直接追加・重複防止、縮小画面での保存、320px幅と動きを減らす設定を確認します。
