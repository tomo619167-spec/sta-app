# Phase 3.5 — 学習の導線を整理

現在の進捗表示・閉じる操作・モード選択・記録画面は[Phase 3.6](phase-3-6.md)で更新しています。本書はPhase 3.5当時の実装記録です。

## 画面と操作

- テーマ詳細・ロードマップ：項目名、読み取り専用の習得度、矢印の一覧。項目全体から専用詳細へ進みます。「…」メニュー、一覧での習得度変更、展開した学習ボタンは廃止しました。
- 進捗：「説明できる・定着した：〇 / 〇項目」。分子は習得度3・4の合計、分母は全項目数です。旧％評価からの自動変換はありません。
- 項目詳細：到達目標、習得度変更、主要操作2つ。「自分の言葉で説明する」「理解を深める」から直接入力を開きます。項目選択から2タップです。
- 項目の編集・確認付き削除は詳細の「…」に集約。追加・表示順の変更・テーマ目標の編集・JSONによる追加はロードマップ管理に残しています。
- アウトプット：タイトル、本文、任意の4段階完成度のみ。習得度や直近完成度の大きな表示はありません。下書き・標準キーボード・長文・履歴比較を維持しています。
- 理解を深める：6種類の問いと「自分の問い」1欄。「問いを保存」と「プロンプトを確認」を独立させました。習得度、仮説・不明点・気づきの入力欄はありません。
- 保存後：項目の場合は「学習項目一覧へ戻る」を主要操作、「同じ項目で続ける」を補助操作にします。テーマの場合は「テーマ詳細へ戻る」を表示します。戻り先は検証済みの対象から生成し、外部のreturn URLやブラウザ履歴に依存しません。
- 下部ナビは実装済みのホームだけを表示。設定はヘッダーへ移動しました。履歴画面・絞り込みは維持し、テーマ・項目詳細から開けます。タイマーの未完成タブは追加していません。

## 問いと外部AI

保存せず「プロンプトを確認」へ進めます。この時点では正式な問い・学習記録・AIフィードバックを追加しません。既存の共通フローを使い、プロンプト確認 → コピー → 手動で貼り付けへ進む → JSON検証 → プレビュー → 保存となります。コピー成功後の自動遷移はありません。種類の選択UIはなく、問いの種類に応じて固定プロンプトを自動生成します。

途中の問い・プロンプト・コピー状態・JSON・ステップは、対象別の既存learning-draftsストアに任意フィールドとして保持します。ブラウザを離れたり再読み込みしても再開できます。問いが変わった場合、以前のAI作業を置き換える前に確認します。閉じれば問いの編集へ戻れ、AIを使わず「問いを保存」することもできます。

AI結果の保存を確認したときだけ、問いとフィードバックを同一トランザクションで登録し、該当下書きを削除します。JSON不正・対象不一致・保存失敗では部分登録せず、下書きと既存データを残します。登録済みの記録からAIを使う場合は、従来の記録ID・版を照合する保存処理を再利用します。出力スキーマは変更せず、v1・v2・v3を引き続き受け付けます。

## データへの影響

IndexedDBはv6のままで、スキーマ変更・既存データの一括移行・評価の変換は行いません。科目、テーマ、項目のIDと関連、習得度履歴、アウトプット、旧％評価、問い、AIフィードバックは維持します。

以前の仮説・不明点・気づきは記録詳細で引き続き閲覧できます。新しい問いだけの編集でも、これらの旧フィールドは保持します。既存の編集中の下書きにも同じ扱いを適用します。習得度と各回の完成度、AI結果は独立しています。
