# プロンプト画面・習得度の微調整

## プロンプト

学習用の外部AI画面から説明文「外部AIへ貼り付け、返ってきたJSONを取り込みます。」、見出し「生成したプロンプト」、手動の「プロンプトを選択」ボタンを削除しました。プロンプト種類を選ぶUIはありません。

「AIで理解を深める」は説明モード（初期値は簡単）、自分の問い、操作ボタンを中心に表示します。全文は初期状態で閉じた「プロンプト全文を確認」に置きました。説明モード・問いの種類・問い本文による自動生成、モードと入力途中の保存、共通JSON形式は変えていません。

「プロンプトをコピー」と「AIの回答を貼り付ける」を常に表示します。コピー後も自動遷移しません。コピーが拒否された場合は全文を開き、端末標準の選択・コピーで対応できます。専用の選択ボタンはありません。エラー、コピー状態、下書き状態は維持します。JSONの検証・プレビュー・保存処理も既存のものを再利用します。

## 習得度

学習項目詳細の独立した習得度領域をなくし、タイトル横のピル型ボタンに集約しました。高さ44px以上、現在の段階、メニューのチェックマーク・選択色を備えます。長いタイトルは折り返し、メニューは小さい画面でもスクロールできます。

未着手／学習中／説明できる／定着したを選ぶと、既存の保存処理で習得度を記録し、表示を更新してメニューを閉じます。保存中の重複操作を防ぎ、失敗時は元の段階と履歴を維持して再選択できます。同じ段階の再選択では重複した履歴を追加しません。

「変更の履歴」から従来の履歴を確認できます。未評価の既存データには段階を自動設定しません。テーマ全体の習得度UI、アウトプット完成度、評価の独立性は維持しています。

## データ・検証

- 型チェック・本番ビルド・整形チェック：成功
- 単体テスト54件：成功
- E2E 99件（33シナリオ × モバイルChromium・モバイルWebKit・PC Chromium）：成功
- スマホのプロンプト画面・320px幅の習得度メニューのスクリーンショットを確認

IndexedDB v6・データ構造・JSON形式は変更していません。科目・テーマ・項目・記録・問い・AI結果・下書き・旧評価を保持します。

既存の単体テストに加え、E2Eで3モードの生成・コピー・JSON取り込み、折りたたみと削除したUI、コピー拒否、4段階の即時保存・選択状態・履歴・保存失敗、320px幅の長いタイトル、完成度との独立性を検証します。

実機Android／iOSのキーボード・音声入力、実際の外部AIの回答品質は未検証です。
