# Phase 2改善 — 外部AIからJSON登録まで

ロードマップの主要操作を「AIでロードマップを作成」に統合します。既存のテーマ詳細・項目一覧・学習対象・評価の導線は維持します。

## 操作

1. 科目・テーマを確認し、到達目標・学習レベル・任意の補足を入力。固定プロンプトを確認してコピー
2. コピー完了を同じ画面に表示。ユーザーが外部AIで生成し、「JSONの貼り付けへ進む」を押す
3. JSONを貼り付け、検証・全件プレビュー・重複確認を経て登録

コピー後にJSON画面へ自動遷移しません。コンパクトな3ステップ表示で現在位置を示します。「戻る」で入力条件・生成プロンプト・JSONに戻れ、入力内容は保持します。生成済みJSONには「JSONを直接取り込む」という補助操作を用意します。クリップボードが拒否されても、手動選択・コピー後にJSONへ進めます。

全ステップを同じ全画面ダイアログで表示し、スクロール領域・固定フッター・VisualViewport対応を再利用します。AI APIの呼び出しはありません。外部AIのサイトを自動的に開いたり、入力を外部へ送信したりしません。

## テーマ別の一時ドラフト

`RoadmapDraft.version: 1`で形式を管理し、テーマIDをキーとしてIndexedDBに保存します。入力条件、生成したプロンプト、コピー完了状態、JSON（不完全な文字列も含む）、入力／プロンプト／JSON／プレビューの位置、画面の開閉状態を保持します。

入力・ステップ変更ごとに保存し、「下書き保存済み」で完了を示します。外部AI利用中に画面が再読み込みされても、保存済みのステップで再開します。明示的に閉じた場合は自動で開き直さず、主要ボタンから続行できます。キャンセルは項目・目標・評価・記録を変更しません。テーマが違えばドラフトも別です。

ドラフトの書き込みは順番に処理し、古い入力が新しい入力を上書きしないようにします。保存に失敗した場合は現在の入力を画面に残し、再試行を表示します。復元に失敗した場合は、新しい下書きで上書きせず読み込みを再試行できます。ブラウザデータ消去・端末間同期には対応しません。保存完了前の強制終了では最新の入力を失う場合があります。

## 再利用とデータ保護

プロンプトは既存の`buildRoadmapPrompt`、JSON検証・形式・重複判定は`lib/roadmap-json.ts`、登録は`StudyRepository.importRoadmap`を利用します。別のJSON形式や保存経路は作りません。プレビューは再検証して復元し、再読み込み後の重複確認は未チェックに戻します。登録直前の対象・重複の再検証も継続します。

IndexedDBは`yohaku-study`のv5へ加算的に移行します。v4からは`roadmap-drafts`ストアを追加するだけで、既存8ストアの行・手動アイコン・習得履歴・旧％評価・関連IDを変更しません。以前のv1〜v3移行も維持し、移行失敗時は元バージョンへロールバックします。

登録前にドラフトの保存待ちを完了し、項目追加と該当ドラフト削除を同一トランザクションで行います。既存項目への上書きはありません。登録やドラフト削除の途中で失敗した場合は、追加した項目を残さずドラフトも保持します。別テーマのドラフトは削除しません。テーマ削除時は、そのドラフトを同じ削除トランザクションに含めます。
